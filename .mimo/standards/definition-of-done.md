# Definition of Done (DoD)

Задача **готова** только когда выполнен КАЖДЫЙ пункт. Иначе — не принято (с явным «НЕ СДЕЛАНО:<причина>», V9).

## Чеклист готовности
- [ ] **Трассировка.** Изменение привязано к коду наблюдения (P/M/B/T/F/S/SEC) из [../../docs/analysis/](../../docs/analysis/README.md) и/или к задаче роадмапа ([../../docs/README.md](../../docs/README.md)).
- [ ] **Соответствие.** Не нарушает ADR/[rules](../rules/rules.md)/[conventions](conventions.md).
- [ ] **Фальсифицируемый тест.** На изменённое поведение есть тест + **proof-of-failure** (V3): показан красным на баге/мутации, зелёным после фикса.
- [ ] **Код вызывается из рабочего пути (V5).** Символ реально дёргается (показан call-site), не «лежит в файле».
- [ ] **Build+test зелёные.** Backend: `mvn clean verify` (10/10 модулей). Frontend: `npm run build`.
- [ ] **Числа замерены (V6).** Где есть перф/латентность/совместимость — приложен вывод прогона, не оценка.
- [ ] **Границы (V7).** Нет import internal чужого модуля; ошибки не проглочены; идемпотентность где нужна.
- [ ] **Scope (V8).** Дифф ⊆ назначенной задаче; ничего смежного «заодно».
- [ ] **Доки/контракты обновлены.** Если менялось API/поведение — обновлён контракт и `docs/`.
- [ ] **Честный отчёт.** Таблица критерий→команда→факт; невыполненное — явно.

## Формат отчёта Mimo (обязателен)
```
## Отчёт по задаче <ID>
| Критерий приёмки | Команда проверки | Факт |
|---|---|---|
| grep устаревшего API → 0 | rg "oldApi" src → | 0 совпадений |
| тест T зелёный | mvn -pl zorrobpm-engine test -Dtest=XIT | BUILD SUCCESS, 1 run |
| proof-of-failure | git stash (фикс) → mvn ...XIT | FAIL (ожидаемо), после фикса PASS |
| замер p95 | приложен лог бенча | 42ms (бюджет ≤100ms) |

НЕ СДЕЛАНО: <пункт> — <причина> (если есть).
Изменённые файлы: <список>. Трассировка: <код наблюдения / задача роадмапа>.
```

## Что Claude сделает при ревью
1. Перечитает диск (не отчёт): `git diff`, grep call-sites, прогон тестов/гейтов.
2. Проверит каждый критерий приёмки **командой** (V1/V2).
3. Потребует proof-of-failure там, где менялось поведение (V3).
4. Вердикт: **принято** → merge в master (только Claude); **НЕ принято** → факты + следующий промт.

> Приукрашивание/«зелёное, но пустое»/«реализовано, но не вызывается» — автоматический отказ.

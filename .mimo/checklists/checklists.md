# Checklists по этапам

Минимальные объективные чеклисты. Перед PR пройти релевантные. Пустой чекбокс = блок.

## Старт задачи
- [ ] `git status` + `git log` выполнены; состояние master/веток понятно.
- [ ] Work order прочитан; трассировка к коду наблюдения (P/M/B/T/F/S/SEC) ясна.
- [ ] Scope ясен: что можно/нельзя трогать (V8). Структурное? → ADR до кода (V10).
- [ ] Feature-ветка создана.

## Дизайн (G2)
- [ ] Критерии приёмки механические (grep/тест/замер), не «на глаз».
- [ ] Затрагиваемые классы/файлы перечислены.
- [ ] Миграции спланированы (Liquibase changeset), обратная совместимость контракта оценена.

## Реализация (G3)
- [ ] Дифф ⊆ scope (V8). Никакого смежного «заодно».
- [ ] Новый код **вызывается** из рабочего пути (V5) — call-site показан.
- [ ] Нет проглоченных ошибок / мока реального пути / cross-internal импортов (V4/V7).
- [ ] `mvn clean verify` (или `npm run build`) зелёный.
- [ ] Контракт/доки обновлены (если менялось API/поведение).

## Тесты (G4)
- [ ] Тест на изменённое поведение с сильным assert (не лог).
- [ ] **Proof-of-failure** показан: красный на баге/мутации → зелёный после фикса (V3).
- [ ] Реальный путь (engine-IT на H2 со схемой), не заглушка.
- [ ] `grep -rn "@Disabled\|@Ignore" src` = 0 (или обосновано).
- [ ] Конкурентные кейсы реально конкурентны (V6).

## Перформанс (G5, если применимо)
- [ ] Замер до/после в бюджете (V6); вывод приложен.
- [ ] `EXPLAIN` на ключевом запросе; нет N+1/full-scan на горячем пути; индекс под запрос.

## Безопасность (G6, если применимо)
- [ ] Тест «401/403 без токена» красный до фикса, зелёный после.
- [ ] Нет дефолтных секретов в prod (fail-fast); CORS не `*`+credentials; нет логов секретов.

## Перед PR (DoD)
- [ ] [definition-of-done](../standards/definition-of-done.md) закрыт.
- [ ] Честный отчёт: таблица критерий→команда→факт; невыполненное — «НЕ СДЕЛАНО:<причина>».
- [ ] PR открыт; **в master не мёржу** (мёржит Claude).

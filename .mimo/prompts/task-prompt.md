# Prompt — Task (как Claude ставит задачу Mimo)

Каждая задача Mimo оформляется этим промтом. Критерии приёмки — **механически проверяемые** (V2), запреты — явные (V4/V8).

```
# Задача <ID> — <короткое имя>     [Приоритет: P0/P1/P2/P3]

## Цель
<что и зачем; 2–3 предложения>

## Трассировка
Код наблюдения: <P/M/B/T/F/S/SEC из docs/analysis>. Роадмап: <T*/U*/C* из docs/README.md>.

## Объём (scope) — строго
Можно трогать: <файлы/модули>. НЕЛЬЗЯ трогать: <границы>. Одна задача (V8).

## Критерии приёмки (объективно, V2)
| # | Критерий | Команда проверки | Ожидаемый факт |
|---|----------|------------------|----------------|
| 1 | <…>      | <grep/тест/замер>| <число/0/зелёный> |
| 2 | proof-of-failure (V3) | откат фикса/мутация → тест | КРАСНЕЕТ, после фикса зелёный |

## Запреты (V4/V8)
- Без @Disabled/skip, без мока реального пути, без ослабления ассертов, без happy-path-as-proof, без косметики вместо сути, без хардкода под тест, без работы вне scope.

## Definition of Done
См. [../standards/definition-of-done.md]. Отчёт — таблицей критерий→команда→факт; невыполненное — явно «НЕ СДЕЛАНО:<причина>».

## Гейты
Пройти: <G3/G4 [+G5/G6]>. Перед PR — self-review по чеклисту этапа.
```

> Если задача требует структурного изменения (модуль/контракт/модель исполнения) — сначала ADR (V10), не код.

# /.mimo — Governance OS

Операционная система команды Mimo. Читать перед взятием задачи.

## Быстрый старт

1. Прочитай [rules/rules.md](rules/rules.md) — 10 правил, действуют всегда
2. Возьми задачу из [workorders/_index.md](workorders/_index.md) — строго по приоритету
3. Выполни, заполни отчёт, открой PR
4. CTO (Claude) ревьюет → мержит в master

## Структура

| Путь | Содержимое |
|---|---|
| `rules/rules.md` | V1–V10, методы верификации, запреты, эскалация |
| `workorders/_index.md` | Все задачи по приоритету |
| `workorders/WO-*.md` | Конкретные задачи с критериями приёмки |

# Playbook — Doc Audit

Поддержание единого источника истины ([docs/README.md](../../docs/README.md) + [docs/analysis](../../docs/analysis/README.md)).

1. **Инвентаризация.** `find . -name "*.md"` (без node_modules/target/.git). Реестр: путь→что→дата→актуальность→дубль.
2. **Сверка с кодом (V1).** Каждое ключевое утверждение проверить grep/чтением исходника. Помечать расхождения.
3. **Классификация.** KEEP / MERGE / DROP с **причиной** (дубль/протухло/противоречит коду). Фиксировать в [_audit/doc-inventory.md](../../docs/_audit/doc-inventory.md).
4. **Один роадмап.** Устранить параллельные планы; всё свести в единый трекер. Архив визий — с баннером «не план».
5. **DROP через git** с коммитом «почему дропнуто»; контент сохранить в трекере перед удалением.
6. **Битые ссылки.** `grep` ссылок на удалённые доки в оставшихся файлах = 0.

**Прецеденты (уже исправлено):** timeCycle «не поддерживается» и «race в BpmnService» — устаревшая память Mimo, опровергнута кодом.

**Анти-имитация:** оставлять утверждение, расходящееся с кодом, или плодить второй роадмап — запрещено.

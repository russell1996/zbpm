# Playbook — Code Review (по диску)

Ревью делает Claude/governor. Проверяем **факт**, не отчёт. Гейт G3.

1. **Дифф.** `git fetch && git diff master...<branch> --stat` и прочитать дифф целиком.
2. **Критерии по командам.** Для каждого критерия приёмки work order — выполнить команду проверки, записать факт (V1/V2).
3. **Proof-of-failure (V3).** Где менялось поведение — воспроизвести/потребовать: откат фикса/мутация → тест красный.
4. **Call-site (V5).** `grep` использование нового символа — реально вызывается из рабочего пути?
5. **Границы/запреты (V4/V7).** `grep -rn "@Disabled\|@Ignore"`; пустые `catch`; ослабленные ассерты; cross-internal импорты.
6. **Scope (V8).** Дифф ⊆ задаче? Нет «заодно».
7. **Гейты.** Прогнать G3/G4 (+G5/G6); полный `mvn clean verify` / `npm run build`.
8. **Вердикт.** ПРИНЯТО → merge в master (только Claude). НЕ ПРИНЯТО → таблица факты + следующий [task-промт](../prompts/task-prompt.md).

**Красные флаги имитации:** зелёный тест без assert; «реализовано», но символ не вызывается; косметика; мок реального пути; оценка вместо замера; дифф шире scope.

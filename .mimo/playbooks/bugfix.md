# Playbook — Bugfix

1. **Воспроизвести.** Написать тест, **воспроизводящий баг** — он должен быть КРАСНЫМ (V3). Без этого фикс не принимается.
2. **Локализовать.** Найти корень по диску (grep/чтение), не по догадке; зафиксировать класс:строку.
3. **Минимальный фикс.** Только корень (V8); без «заодно отрефакторю».
4. **Зелёный + регресс.** Тест из шага 1 зелёный; существующие IT не сломаны (`mvn clean verify`).
5. **Proof-of-failure (обязателен).** Показать: откат фикса → тест снова красный.
6. **Трассировка.** Привязать к коду наблюдения/инциденту; если выявил новый дефект-паттерн — в память проекта.
7. **PR + честный отчёт.**

**Анти-имитация:** «не воспроизвёл, но поправил» = не принято. Зелёный без доказанного красного до фикса = не принято.

# Playbook — Testing

Гейт G4. Цель: тест **доказывает** поведение (V3), а не красит зелёным.

1. **Что наблюдаем.** Определить наблюдаемый результат: статус активности, переменная, число строк, инцидент, ответ API.
2. **Сильный assert.** Assert именно на результат, не на лог/«не упало».
3. **Реальный путь.** engine-IT на H2 с реальной схемой Liquibase; не подменять движок/БД заглушкой там, где проверяется реальное (V4).
4. **Proof-of-failure.** Показать тест КРАСНЫМ: откат фикса или мутация кода → тест падает. Затем зелёным.
5. **Конкурентность.** Joins/таймеры/доставка — реальная конкуренция (2 потока/«ноды»), не последовательная имитация (V6).
6. **Без скипов.** `grep -rn "@Disabled\|@Ignore" src` = 0 (или явно обосновано).
7. **Naming.** `*IntegrationTests`/`*IT` (интеграционные), `*Tests` (unit).

**Команды:** `mvn -pl <module> test -Dtest=<XIT>`; мутация/откат → ожидать FAIL; полный `mvn clean verify`.

**Анти-имитация:** тест без assert, лог-вместо-assert, мок реального пути, «всегда зелёный» — запрещены.

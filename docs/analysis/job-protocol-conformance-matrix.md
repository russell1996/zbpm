# Матрица протокола job — 8.9 docs | Zeebe 8.5 live | ours | вердикт

WO-OPS-30 Ф2а. Поведение измерено на **живом Zeebe 8.5.0** (`camunda/zeebe:8.5.0`, стенд
`zbpm-cmp-zeebe`, gRPC `127.0.0.1:36500`) и на **нашем движке** (тот же список кейсов, тот же
живой путь: `RuntimeService`/`ActivityService` → handler'ы → outbox-тело задания → таблицы).
Дизайн/спецификация — **docs.camunda.io 8.9**.

**Один источник правды на обе стороны:** список кейсов
`zorrobpm-engine/src/test/resources/job-protocol-cases.json` (BPMN + шаги + ожидания),
копии сценариев — `docs/analysis/c8-oracle/scenarios/f2a-*/` (`process.bpmn` + `scenario.json`,
формат F0-шаблона, расширен шагами). Оракул (`docs/analysis/c8-oracle/job-protocol.js`) перед
каждым прогоном **побайтово сверяет** `process.bpmn` сценария с канонической моделью из
`zorrobpm-engine/src/test/resources/job-protocol/` — расхождение валит прогон (иначе «оба
движка» мерили бы разные модели).

**Итог: 9 `match`, 5 `ours differs`** (из них 1 — сознательное отличие «by design»).
Расхождения по корням — в отчёте `docs/internal` §5.

Особенности измерения:

* **инцидент на live-8.5 не читается** — Gateway API 8.5 не отдаёт инциденты, а Operate на
  стенде нет; наблюдаемо только отсутствие следующего задания. У нас инцидент читается —
  поэтому в колонке «ours» текст инцидента приведён, а в колонке «live» стоит пометка.
* **переменные** — сырой JSON: у live это тело активированного задания, у нас — переменные
  в теле задания (outbox). Порядок ключей нормализован (сравнивается содержание, не порядок).
* **`retries`**: у live это поле активированного задания (воркер его видит), у нас — остаток
  бюджета в БД движка; пометка `workerVisibleRetries=NONE` означает, что в ТЕЛЕ задания
  бюджета нет (строка R4).

## Откуда взяты «live» и «ours»

* **live** — прогон `node docs/analysis/c8-oracle/job-protocol.js` на живом Zeebe 8.5.0; сырые
  наблюдения в `docs/analysis/c8-oracle/scenarios/f2a-*/result-8.5.json`.
* **ours** — прогон `JobProtocolConformanceIntegrationTests` (failsafe; имя `*IntegrationTests`
  подобрано так, чтобы тест забирал CI — урок WO-C8-40: `*IT` не попадает ни в surefire, ни
  в failsafe). Сырые наблюдения — `zorrobpm-engine/target/job-protocol-observed.json`,
  ожидания — в `job-protocol-cases.json` (`expect.observations`); значения берутся из измерения
  на живом 8.5, а не из нашей реализации (G-Q).
* **POF** (мутации прода, RED→GREEN) — в отчёте `docs/internal` §6.

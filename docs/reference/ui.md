## Интерфейс (SPA)

Единое приложение вместо Operate/Tasklist/Cockpit (`zorrobpm-frontend`, Vue 3 + shadcn-vue):

- **Обновление в реальном времени** по SSE: одно соединение на браузер (остальные вкладки получают события через вкладку-лидера); рядом с поиском в шапке появляется индикатор канала **только при сбое** (красный — нет связи, янтарный — переподключение), детали по клику.
- **Страница экземпляра:** BPMN-схема, переменные (обновляются по событиям и при открытии вкладки), задачи, инциденты, подпроцессы, история; экспорт **«Диагностика JSON»**.
- **Запуск процесса:** один выпадающий список «Шаблон» (первый пункт — «Без шаблона — ввести вручную»), один редактор переменных, при замене введённых строк шаблоном — тихий тост «Отменить».
- **Длинный текст в таблицах** (сообщения инцидентов, ошибки задач и т. п.) открывается по клику в диалоге целиком, с копированием.
- JSON-переменные редактируются компактным редактором (свёрнут по умолчанию, форматирование без потери значений, открытие в диалоге).
